# BulkRNAseq_sea_scallop
## Microbial ecology with Bulk-RNAseq

This repository contains coursework and analyses focused on processing raw DNA sequencing data through a complete bioinformatics workflow—from quality control to statistical analysis and scientific interpretation.

The course emphasizes hands-on experience with real sequencing data and introduces key bioinformatics tools and methods used in microbial ecology and genetics research.

---

## Course Overview

This course covers the full pipeline of DNA sequencing data analysis, including:

- Raw sequencing data processing and quality assurance
- Sequence quality trimming and filtering
- Contig assembly and sequence alignment
- Use of reference databases for annotation and comparison
- Statistical analysis and interpretation of sequencing results
- Focuses on Bulk RNA-seq Data with DADA2 analysis
